# BashaKhuji

BashaKhuji is a platform designed to help users find rental houses, apartments, hostels, sublets, and commercial properties efficiently. The platform aims to simplify property searching by connecting tenants and property owners through a centralized system.

## Overview

Finding a suitable property can be time\-consuming and challenging. BashaKhuji provides a structured solution that enables users to search, filter, and contact property owners based on their location, budget, and property preferences.

## Features

- Search properties by location
- Filter listings by rent range
- Browse apartments, houses, hostels, and sublets
- View property details and images
- Contact property owners directly
- Save and manage favorite listings
- User registration and authentication
- Property owner dashboard
- Responsive design for mobile and desktop devices

## Installation

Clone the repository:

git clone [https://github.com/sibleecse\-gif/bashakhuji.git](https://github.com/sibleecse-gif/bashakhuji.git)

cd bashakhuji

Install dependencies:

npm install

Start the development server:

npm start

## Configuration

Create a .env file in the project root directory:

PORT=5000

MONGODB\_URI=your\_database\_connection\_string

JWT\_SECRET=your\_secret\_key
